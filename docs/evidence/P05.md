# P05 后端草稿与预设模块验收

运行标识 `20261120-p05`，日期 2026-11-20。以提交 `a045e54` 及工作区内的 P03/P04 前端实现为基线，新增可编译启动的 `backend/` Maven 模块（Java 21、Spring Boot 3.5.16、Spring MVC / Spring JDBC、sqlite-jdbc 3.45.3.0），实现**房间草稿创建、房间快照、大厅活跃列表、预设读取与预设复制**；同时把前端演示用的模拟服务移出开发路径，新增对接真实后端的 `/admin` 管理台。总结果为 P05 通过：后端 **64 项**测试（1 项因本机无符号链接权限跳过），前端 29 项组件测试与 6 项浏览器测试全部通过，五个接口经真实 HTTP 冒烟验证。

模型网关在本阶段只有测试替身与本地联调实现，真实供应商适配与模型质量评估推迟到 P08；确认开场 `/start` 与 SSE 事件订阅推迟到 P06/P07。

## 测试数据与隔离

- 集成测试在 `backend/target/test-db/p05-<uuid>/panel-test.db` 建立本轮专用临时文件库，通过 `@DynamicPropertySource` 注入 `panel.db.path` 与 `panel.db.allowed-root`，JVM 退出时递归清理（含 `-wal`、`-shm`）。
- 业务库 `data/panel.db` 在整轮测试与冒烟中**从未被创建**；`P05-DB-ISOLATION` 直接断言 `pragma_database_list` 的 `main` 文件等于注入路径。
- 数据库脚本只有根目录 [init.sql](../init.sql)；`pom.xml` 在构建时把它放进 `classpath:db/init.sql`，避免出现第二份 DDL。
- 初始化幂等：`P05-PRESET-VALID` 在本轮新建的空库上连续执行两次，预设 5 条、成员 25 条、内容指纹不变。
