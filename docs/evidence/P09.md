# P09 前后端主链路联调

2026-11-20，基线 `cbac8d4` 和当前工作区。使用 Vue 3.5.46、Vite 7.3.8、Spring Boot 3.5.16、Java 21、Playwright 1.65.1 和本机无头 Chrome。前后端均使用真实应用进程和独立端口。Spring 显式使用本轮新建的 SQLite 文件，测试脚本退出时清理。可控模型上游和已配置的 `deepseek-flash` 分开执行。

| 用例 | 预期 | 实际 | 结果 |
| --- | --- | --- | --- |
| E01 创建到总结 | 浏览器确认阵容后开场，最终总结可见 | 可控上游和真实模型均由浏览器创建阵容、开场并完成。真实模型有 6 条专家发言和 41 条事件。总结先于完成事件 | PASS |
| E02 并行旁观 | 大厅旁观已有房间，两个活动房间数据隔离 | 同时看到两个活动房间。旁观进入原房间，另一场实录及回放没有甲场内容或房间 ID | PASS |
| E03 直播提炼 | 完成前展示结论，暂缓保留旧结果，随后恢复 | 可控上游产生 5 次 FRESH 和 1 次 STALE，浏览器依次看到三个状态及旧结论。真实模型产生 4 次 FRESH 和 2 次 STALE | PASS |
| E04 断线与回放 | 断线期间后端继续，恢复后从游标精确补齐 | 浏览器离线期间实录继续增长，恢复网络后重新打开同一房间。HTTP 回放从第 9 号事件之后收到 33 个连续事件，终态追平返回 204 | PASS |
| E05 容量和 Origin | 两场执行时第三个草稿保留，外部 Origin 被拒 | 第三场收到 429/B0004，仍为 DRAFT 且游标为 0。外部 Origin 收到 403/B0006 | PASS |
| E06 三种视口 | 1920×1080、1366×768、390×844 检查布局和独立滚动 | 能正常展示 3 个席位和总结，检查根容器与内容区滚动方式。窄屏通过键盘切换标签，点击证据定位到实录 | PASS |
| E07 预设复制 | 读到五条预设，重复复制生成两个独立草稿 | 五条预设加载，同一预设两次返回 201、不同房间 ID、相同议题且游标均为 0 | PASS |

联调发现 Vite 默认转发至 8080，Spring 默认监听 8081。修正默认目标并支持 `PANEL_BACKEND_URL` 指定联调地址。断开 SSE 时发现普通 `IOException` 进入全局 JSON 异常处理器，导致已提交的事件流再尝试写入 JSON。修正后，断开、重新打开及回放从三个视口验证通过，日志未出现对应的异常处理错误。握手阶段的非法游标请求返回 JSON 400/B0001。
