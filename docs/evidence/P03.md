# P03 大厅与阵容验收

基线提交为 `a045e54`。按 P02 的 API 和联调样例实现 U01、U04、F01、F02 的前端交互。阵容预览使用 `/discussions/:id/roster`，直接打开时按 ID 读取快照。确认或旁观均进入 `/discussions/:id` 的只读房间入口。

## 本地运行

在 `frontend` 目录执行以下命令。验收使用 Node.js 22.19.0、Vue 3.5.46、Vue Router 4.6.5 和 Vite 7.3.8。

```powershell
npm ci
npm run dev:fixture
```

开发入口为 `http://127.0.0.1:5173`。fixture 从 P02 样例读取预设及初始房间，进程重启后恢复初始数据。普通开发入口 `npm run dev` 将 `/api/v1` 转发至 `http://127.0.0.1:8080`。
